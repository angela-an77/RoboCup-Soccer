# RoboCup-Soccer
Mobility consists of the scripts uploaded to each Teensy. We have one teensy controlling the two front wheels and line sensors. We have another teensy controlling the the third back wheel, the dribbler, and the kicker. 

Vision consists of the main code that is saved to the OpenMV camera.

Our Raspberry Pi 5 controls our components and strategizes using ROS, and soccer_ws consists of the workspace that has all of our nodes.
